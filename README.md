# Koromosho Springs

Koromosho Springs is a personal portfolio concept for an Eldoret-first water delivery experience. It is not presented as an operating company and does not process real orders or payments.

## Direction

- Contemporary Kenyan visual language inspired by Rift Valley greens, wet stone, rich soil, and woven texture
- Clear sample pricing in Kenyan shillings and Eldoret-specific concept delivery zones
- Honest interactive order estimator with no fake submission state
- Responsive, keyboard-friendly single-page experience with reduced-motion support

## Stack

Semantic HTML, modern CSS, and vanilla JavaScript. No build step is required.

## Run locally

Open `index.html` directly, or serve the directory with any static server:

```powershell
npx.cmd serve .
```

## Publishing note

The page uses `noindex, nofollow` until a final deployment URL and publication approval are confirmed. Replace that directive and add absolute social metadata only at release time.
